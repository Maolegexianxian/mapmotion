# Web 地图动画工具 — 产品需求文档（PRD）

版本：v1.0  
日期：2025-11-26  
状态：正式草案（企业级）  
适用范围：产品、设计、研发、测试、运维、SRE、合规

## 0. 变更记录
- 2025-11-26：首次发布 v1.0（定义范围、功能与非功能标准、里程碑与验收）。

## 1. 产品概述
- 使命：让不懂 AE 的用户在浏览器内快速制作高质量地图动画，用模板与向导降低学习成本。
- 价值：分钟级产出、社媒友好、云协作与品牌一致性、可升级的三维与高质量导出。
- 范围：底图与样式、地点检索与要素、路线与镜头动画、标签与数据可视化、三维地形与建筑、导出与项目管理。

## 2. 目标用户与场景
- 用户画像：
  - 动效入门用户（自媒体、教育/培训、市场与品牌团队）。
  - 新闻与数据可视化编辑（图文视频工作室、资讯团队）。
  - 行业宣传与汇报团队（旅游、航空、物流等）。
- 核心场景：
  - 旅行/航线动画、国家/城市介绍、事件区域覆盖、门店/网点分布、趋势/热力可视化。

## 3. 战略目标与非目标
- 战略目标：
  - 零门槛：强向导 + 预设镜头/标签/模板，避免关键帧与曲线学习。
  - 高效产出：1080p 快速导出，服务器端兜底高质量导出（MP4/图像序列）。
  - 专业升级：三维地形/建筑、品牌模板、项目与团队协作。
- 非目标：
  - 复杂 GIS 分析（缓冲区、空间聚合、网络分析）不在工具内实现。
  - 全面替代 AE 的综合合成/特效能力不在本阶段目标内。

## 4. 术语与定义
- 底图样式：地图渲染风格（颜色、线宽、字体、阴影、要素显隐），遵循 MapLibre Style Spec。
- 要素：地理对象（点/线/面）如城市、POI、路线、边界、多边形。
- 镜头卡片（Item）：时间线中的动画片段，如推进、环绕、标签出现、路径移动。
- 项目：包含场景与时间线配置的制作工程，可保存、分享与导出。
- 导出档位：浏览器端快速导出与服务器端高质量导出的分级方案。

## 5. 功能需求（带编号与验收）

### FR-001 底图与样式库
- 描述：提供内置样式与主题生成（从图片/品牌色提取），支持颜色、线宽、字体、阴影、要素显隐。
- 交互：样式选择与预览；一键主题生成；保存自定义样式。
- 验收标准：
  - 切换样式≤1s；主题生成≤2s；样式应用后预览无闪烁。
  - 自动显示数据源署名与版权信息，位置与内容符合供应商要求。

### FR-002 地点检索与要素管理
- 描述：在线检索国家/城市/POI；结果可绘制为要素并编辑样式与标签；支持自定义绘制与导入。
- 交互：搜索框、结果列表、一键添加到场景、右栏编辑要素属性与标签。
- 验收标准：
  - 缓存命中响应≤500ms；失败重试 3 次并反馈错误原因。
  - 要素可拖拽编辑并保存；支持撤销/重做（最近 50 步）。

### FR-003 路线与镜头动画（向导式）
- 描述：输入起终点与交通方式（驾车/步行/航线/大圆），自动生成路线与镜头卡片（推进/环绕/俯仰/旋转）。
- 交互：路线向导（起点/终点/停靠点/速度/时长）；时间线添加与调整镜头卡片（时长、强度、缓动）。
- 验收标准：
  - 路线生成≤1s（缓存命中）；镜头过渡平滑无抖动；播放帧率≥60fps（二维）。
  - 时间线支持卡片拖拽与吸附；撤销/重做与快照一致。

### FR-004 标签模板与自动避让
- 描述：标签模板（标题、副标题、图标、动态字段）；自动碰撞检测与优先级策略，支持手动微调与锁定。
- 交互：应用模板→自动布局→允许手动拖拽与锁定；密度阈值超限自动折叠或聚合。
- 验收标准：
  - 多语言文本渲染正确；标签不重叠或出现明显遮挡（在阈值内）。
  - 手动锁定后导出位置稳定；模板保存与复用有效。

### FR-005 数据导入与可视化
- 描述：导入 CSV/TSV，列映射到样式（颜色、大小、线宽），支持经纬度点/线/面与热力图层。
- 交互：字段映射向导（name/lat/lon/value），提供配色方案与阈值控制。
- 验收标准：
  - 1–10k 行导入≤2s；异常数据明确提示；可视化渲染稳定无阻塞。

### FR-006 三维地形与建筑挤出
- 描述：基于 DEM 地形起伏，OSM/向量瓦片建筑挤出；镜头与光照可调；质量/性能档位切换。
- 交互：开启三维→选择档位（低/中/高）→建筑高度模式（统一/属性驱动）。
- 验收标准：
  - 低档位在中端设备 30–60fps；高档位可降级且导出分块渲染。

### FR-007 模板与品牌主题
- 描述：提供组合模板（路线+镜头+标签+片头片尾）；品牌主题（色板、字体、图标）。
- 交互：模板一键应用→预览→保存为自定义模板；品牌主题全局生效。
- 验收标准：
  - 模板应用≤1s；模板替换不破坏现有时间线结构；品牌风格一致。

### FR-008 导出与发布
- 描述：浏览器端快速导出（WebM/H.264）；服务器端高质量导出（MP4/PNG 序列/透明背景）；社媒预设与水印。
- 交互：导出预设（分辨率、码率、时长裁剪）、进度显示、失败重试与错误报告；完成后链接与文件管理。
- 验收标准：
  - 30s 动画浏览器端≤60s 导出（参考设备）；服务端失败率<1%。
  - 导出视频音画同步；透明背景 PNG 序列无边缘伪影。

### FR-009 项目管理与分享
- 描述：自动保存、版本快照、回滚、只读分享链接与访问控制；组织/团队协作（后续阶段）。
- 交互：快照创建与对比；分享权限（公开/组织/指定用户）。
- 验收标准：
  - 自动保存不打断操作；快照恢复 100% 一致；分享链接可配置有效期与密码。

### FR-010 账户与计费/配额
- 描述：套餐（Free/Pro/Team）、导出配额与速率控制、账单与发票下载。
- 交互：用量仪表盘、升级流程与通知、失败重试与客服工单入口。
- 验收标准：
  - 用量统计准确；配额触达提示清晰；扣费与发票合规。

## 6. 非功能性需求（NFR）
- 性能：
  - 二维预览≥60fps；三维低档位≥30fps；交互延迟≤50ms；样式切换≤1s。
- 可靠性与可用性：
  - 服务端导出成功率≥99%；月可用性≥99.9%；关键依赖（队列、对象存储、CDN）有降级与重试。
- 安全与合规：
  - 第三方 API Key 仅在服务端管理；用户数据加密传输；敏感信息加密存储。
  - 版权署名自动化；GDPR/CCPA 合规；审计日志与访问控制。
- 兼容性：
  - 浏览器：Chrome/Edge/Safari（最近两版）；移动端提供简化功能与导出限制。
- 可观察性：
  - 指标：导出成功率、耗时、外部 API 错误率、FPS、内存/CPU；日志结构化与分布式追踪。
- 国际化与可访问性：
  - 中文优先，多语言扩展；键盘导航、对比度、字幕基础支持。

## 7. KPI 与度量
- TTFX（首次导出时间）中位数≤10分钟；WAU、导出次数、成功率。
- 模板使用率与二次编辑率；客服工单平均响应/解决时长。

## 8. 风险与缓解策略
- 外部 API 配额与变更：多供应商与代理缓存；速率限制与降级策略。
- 浏览器编码兼容：提供服务端高质量兜底；分块渲染与断点续导。
- 三维性能与标签布局：档位与密度控制；允许手动微调与锁定。
- 数据与版权：自动署名与尾注；水印与合规提示。

## 9. 依赖与假设
- 依赖：瓦片/Geocoding/Directions/DEM 数据源、对象存储与 CDN、支付与账单系统。
- 假设：用户网络质量可达预览与导出要求；目标设备满足浏览器与 WebGL 要求。

## 10. 发布计划与里程碑
- M1（4 周）：底图/样式、检索、路线、基础镜头、标签模板、1080p 快速导出。
- M2（4 周）：item 时间线、CSV 可视化、项目保存/分享、预设模板。
- M3（6 周）：三维地形/建筑、服务端高质量导出、品牌模板与授权。
- M4（4 周）：团队协作、多语言、计费与配额、监控与 SRE 完整化。

## 11. 验收用例示例（GWT）
- 用例 UC-001：路线向导
  - Given：用户输入起点/终点并选择驾车；
  - When：点击生成路线并预览；
  - Then：≤1s 出路线，镜头推进与路径移动平滑，二维预览≥60fps。
- 用例 UC-002：标签模板
  - Given：用户为城市要素应用“城市标签（标题/副标题/图标）”；
  - When：自动布局并预览；
  - Then：标签无重叠，手动微调可锁定，导出位置保持。
- 用例 UC-003：导出
  - Given：项目长度 30s，选择“社媒 1080p”预设；
  - When：浏览器端快速导出；
  - Then：≤60s 完成导出，音画同步，无明显压缩伪影。
